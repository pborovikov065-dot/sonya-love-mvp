# Соня.Любовь — MVP

## Запуск локально
1. Распакуйте архив.
2. Откройте `index.html` в браузере.

## Демо-доступ
- Логин: `сона`
- Пароль: `1503`

## Что внутри
- `index.html` — приложение (HTML, CSS и JavaScript в одном файле)
- `README.md` — эта инструкция
- `assets/` — папка для будущих фотографий и других ресурсов

## Важно
Это демонстрационный MVP: данные хранятся в `localStorage` текущего браузера. Вход не является настоящей защитой, а покупки не отправляют уведомления. Для публикации на GitHub Pages достаточно загрузить содержимое архива в репозиторий и включить Pages.
